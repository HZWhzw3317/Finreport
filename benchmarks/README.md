# 评测方法与结果

本目录记录一次可复现的 A 股 2023 年报抽取评测，用于验证 `finreport` 在
真实公告 PDF 上的规模、质量与效率。

## 1. 数据隔离

评测使用独立的 MySQL schema 和 PDF 目录，不写入生产库：

| 项目 | 生产库 | 评测库 |
| --- | --- | --- |
| MySQL | `finreport` | `finreport_bench` |
| PDF | `data/pdfs/` | `data/pdfs_bench/` |

`scripts/benchmark.py` 会拒绝连接名为 `finreport` 的库，避免误写。
评测前后生产库计数保持 `company=2 / report=2 / statement=12 / statement_item=213`。

## 2. 样本设计

- 报告期：**2023 年年度报告**
- 样本量：**50 家**（随机种子 `42`，排除 `ST/*ST` 和 B 股）
- 板块配额：主板 29 / 创业板 11 / 科创板 6 / 北交所 4
- 金融企业：**5 家**（西部证券、浦发银行、无锡银行、江苏银行、兴业证券）
- 名单：`benchmarks/companies_2023.txt`

## 3. 复现方式

```powershell
$env:DATABASE_URL = "mysql://finreport:finreport@127.0.0.1:3306/finreport_bench?charset=utf8mb4"
$env:PDF_DIR = "./data/pdfs_bench"

# 全流程：建库 -> 抽样 -> 同步 -> 下载 -> 解析 -> 指标
conda run -n finreport python scripts/benchmark.py run --limit 50 --year 2023 --financial 5 --max-backup 30 --recreate

# 只重算指标（复用已入库数据）
conda run -n finreport python scripts/benchmark.py metrics --year 2023 --limit 50 --run-json benchmarks/timings_2023_50.json
```

> 全流程约 40–60 分钟；LLM 兜底比例取决于报告格式。

## 4. 指标口径

| 指标 | 定义 |
| --- | --- |
| 下载成功率 | `download_status='done'` / 报告总数 |
| 解析完成率 | `parse_status ∈ {done, needs_review}` / 已下载 |
| 最终通过率 | `parse_status='done'` / 已解析报告 |
| 待人工复核率 | `needs_review=1` / 已解析报告 |
| 规则独立完成率 | `statement.source='rule'` / 报表总数（未触发 LLM） |
| LLM 兜底参与率 | `statement.source='llm'` / 报表总数 |
| 核心科目覆盖率 | 每张报表命中的 `is_core=1` 科目 / 应有核心科目 |
| 勾稽通过率 | 从 `statement_item` 重算 BS/IS/CF 恒等式，容差 1% 相对或 1 绝对 |
| 原始勾稽通过率 | 排除 `is_derived=1` 的推算科目后重算 |

说明：

- 所得税费用兼容“带符号”和“括号表示费用”两种列示口径；
- 现金流量表勾稽要求经营/投资/筹资三项齐全，汇率变动影响可选。

## 5. 结果（2023 年报，50 家）

| 指标 | 结果 |
| --- | ---: |
| 样本公司 | 50 家 |
| 年报 / PDF | 50 份（100% 下载成功） |
| 报表 | 293 张 |
| 科目 | 7,558 条（去重 98 个科目） |
| 规则独立完成率 | **64.16%**（188/293） |
| LLM 兜底参与率 | **35.84%**（105/293） |
| 最终通过率 | **90.00%**（45/50） |
| 待人工复核 | **10.00%**（5 份） |
| 平均置信度 / 中位数 | **0.9690 / 1.0** |
| 核心科目覆盖率（均值） | **91.13%** |
| 核心科目覆盖率 ≥80% 的报表 | **96.59%** |
| 资产负债表勾稽通过率 | **100.00%**（95/95） |
| 利润表勾稽通过率 | **100.00%**（89/89） |
| 现金流量表勾稽通过率 | **100.00%**（96/96） |
| 推算科目占比 | 1.44%（109 条） |
| PDF 体积 / 数据库体积 | 207.0 MB / 5.2 MB |
| 单份年报平均解析 | 37.3s（22 份复跑，含缓存） |

冷启动参考：5 家冒烟测试平均 **83.9s/份**（无缓存）。

完整报告见 `report_2023_50.md` 与 `report_2023_50.json`。
